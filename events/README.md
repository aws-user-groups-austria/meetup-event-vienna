# events

One folder per meetup, named `<date>-<title slug>`, for example
`2026-10-20-aws-meetup-vienna-53`. Each holds `source.json` (the Meetup link
and overrides, written by hand or by `make new`), `event.json` (generated by
`make sync`, do not edit), and optionally `assets/` and a saved `page.html`.
See `../README.md`.
