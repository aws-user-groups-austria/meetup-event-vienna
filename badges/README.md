# badges

The group's attendee badges (stickers), exported from the Canva design
"UG-Attandee-Badge-Stickers (First-Timer, Host, Speaker)" as transparent PNG,
1200 x 1200: `leader.png` (page 2), `host.png` (page 11), `speaker.png` (page 3),
`first-timer.png` (page 1). `all-timer.png` is new, for regular members: made
from the First-Timer badge, recoloured green (#2ECC71 on #0A2618) and set
"All-Timer" in Amazon Ember Bold; it is also page 18 of that Canva design.
Referenced as `badges/<file>` from `../community.json`.
