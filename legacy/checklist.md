# Meetup Preparation Checklist

## 2 months before
- [ ] Pick a date & venue
- [ ] Confirm host company
- [ ] Update `config/meetup.ts` with date, venue, host

## 4-6 weeks before
- [ ] Pick a topic for the meetup
- [ ] Find 2 speakers (use Sessionize or reach out directly)
- [ ] Update `config/meetup.ts` with talk details

## 3-4 weeks before
- [ ] Schedule meetup on Meetup.com
- [ ] Generate prep guide (GitHub Actions or local)
- [ ] Send prep guide to host company
- [ ] Create event visuals with sponsor logos

## 2 weeks before
- [ ] Start promoting on LinkedIn and Slack
- [ ] Schedule 40 seats, expand to 60 one week before
- [ ] Generate slide deck (GitHub Actions or local)

## Day of meetup
- [ ] Arrive early to set up
- [ ] Test projector and audio
- [ ] Welcome attendees
- [ ] Take photos for social media

## After meetup
- [ ] Post photos and thank sponsors
- [ ] Share recorded talks (if applicable)
- [ ] Send thank you to host
- [ ] Update meetup number for next event
